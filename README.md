CodeAlpha Web Scraping Project

Project Overview

This project collects book information from the Books to Scrape demo website using Python web scraping techniques.

Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

Data Collected

* Book Title
* Price
* Availability

Project Features

* Scrapes book data from multiple pages.
* Stores the collected data in a Pandas DataFrame.
* Checks for missing values and duplicate rows.
* Exports the final dataset to a CSV file.

Dataset

The scraped dataset contains 1,000 book records and 3 columns.

Files

* CodeAlpha_WebScraping.ipynb — Python code and analysis.
* CodeAlpha_WebScraping (1).csv — Scraped dataset.

Website

Books to Scrape

Purpose

Created as a web scraping project for the CodeAlpha Data Analytics Internship.
